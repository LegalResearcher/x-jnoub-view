# X Views (Browser)

يسحب تغريدات حساب `@aljanoubvoice2` ويرسل طلب «مشاهدات فيديو تويتر مجانية» (الخدمة 9335، الكمية 500)
لرابط واحد من الطابور في كل تشغيل، عبر فتح الموقع وتسجيل الدخول (بدون مفتاح API).

## الإعداد
Settings > Secrets and variables > Actions > New repository secret:
- `SITE_USERNAME`: اسم المستخدم في الموقع
- `SITE_PASSWORD`: كلمة المرور

(اختياري) إن لم تضف بيانات الدخول وأضفت `API_KEY` يعمل بوضع الـ API.
(اختياري) متغير `NITTER_INSTANCES` (Variables أو داخل الـ workflow) لتغيير مرايا Nitter.

## مصدر التغريدات
تويتر لا يوفر قراءة عامة مستقرة. يجرّب السكربت بالترتيب: واجهة العرض المضمّن، ثم RSS من مرايا Nitter.
تُتجاهل إعادة التغريد والردود. إن فشلت كل المصادر يظهر السبب في السجل وتُعاد المحاولة في التشغيل التالي.

## كيف يعمل
- أول تشغيل: يأخذ أحدث تغريدة فقط.
- بعدها: كل تغريدة جديدة تدخل الطابور بالترتيب، ويُنفَّذ الأقدم أولاً.
- الرابط الذي يفشل 3 مرات يُتخطى.
- فشل تسجيل الدخول أو نفاد الرصيد يوقف التشغيل.
- عند الفشل في التشغيل اليدوي تُرفع لقطة شاشة باسم `debug` (تُحذف بعد يوم).

## تصفير الحالة
احذف الملفات داخل `state/` (ما عدا `.gitkeep`).

## ملاحظة
المستودع عام: ملفات `state/` مرئية للجميع. لا تضع بيانات الدخول في أي ملف.
